Preconditions for Initiating Automation Execution on the Client Device


  • Network Connectivity : Ensure that both the Test PC/Laptop and the Client (STB) are connected to the same network. A LAN (wired) connection is highly recommended for better stability

  • Enable Developer Options : On the Client (STB), navigate to Settings and enable Developer Options to allow connect client device over ADB connection.

  • Content Approval Setting : Content approval is disabled from the SP user settings to prevent permission-related interruptions during test execution.

  • ADB Platform Tools Installation : Ensure ADB platform tools are installed on the Test PC/Laptop and the ADB executable path is added to the system’s environment variables, verified by running [adb version].
